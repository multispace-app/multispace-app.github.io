What it really
does

No fluff: what happens on your phone.

Your phone,
your data,
your rules.

Separate data per clone
Each clone keeps its session and files apart from the original.
Shared content, if you want
A new clone can reuse the heavy files of another clone of the same game: they take up space only once.
Own identifier, optional
You can give the clone its own device identifier. The risk is explained first.
Everything stays on your phone
No account or sign-up. Reports are only sent if you send them.

Own identifier

Makes each account look like it is on a different phone.

Some games link the accounts they see on the same phone. This way, each clone presents its own identification.

Without the option
Account 1Account 2→1 identification
The game sees a single phone
With the option
Account 1→ID AAccount 2→ID B
The game sees two phones
  • Use it if the game mixes your accounts.
  • Keep in mind some games may react to it; you accept the risk.

Frequently asked questions

Do I need root?

No.

Does it work with every game?

No. Some games reject clones. See the tested apps in the list.

Why is it not on Google Play?

You download it straight from this page; compare the SHA-256 fingerprint.

Do I have to download the game again?

The first clone does download everything. The next ones of the same game can reuse that download.
